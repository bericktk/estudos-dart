# Mini Desafio

## Crie um programa que:
**1 - Declare duas variáveis inteiras:**
- numero1
- numero2

**Exiba:**
- Soma
- Subtração
- Multiplicação
- Divisão
- Divisão inteira
- Resto da divisão

Exemplo de saída:
``` dart
Número 1: 20
Número 2: 6

Soma: 26
Subtração: 14
Multiplicação: 120
Divisão: 3.3333333333333335
Divisão inteira: 3
Resto: 2
```

## Desafio adicional
### Depois de resolver o exercício, explique com suas palavras:

**Por que o operador ~/ existe, se já temos o operador /?**

O operador **~/** existe para retornar o quociente inteiro de uma divisão, descartando a parte decimal.

**Isso é útil em situações como:**
- Calcular quantas páginas completas existem em uma lista.
- Descobrir quantas caixas completas são necessárias para armazenar itens.
- Dividir alunos em grupos completos.
- Obter índices inteiros para listas.
